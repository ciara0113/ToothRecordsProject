1. Input data
    1.1 Get number of people
        1.1.1 Prompt for number of people in the family
        1.1.2 Read the number
        1.1.3 While number is less than 1 or more than 6
                  Print "Invalid number of people, try again"
                  Read the number
    1.2 Create a names array (one name per person)
        Create a 3D teeth array [people][2 rows][8 teeth]
    1.3 For each person
        1.3.1 Get name
              Prompt for the name, read it, store it in the names array
        1.3.2 Get uppers (row 0) - see 1.4
        1.3.3 Get lowers (row 1) - see 1.4
    1.4 Get a row of teeth (person, row)
        1.4.1 Prompt for the teeth, read the string, convert to upper case
        1.4.2 Repeat until the string is valid
                  If any character is not I, B or M
                      Print "Invalid teeth types, try again" and read again
                  Else if the string has more than 8 characters
                      Print "Too many teeth, try again" and read again
        1.4.3 Store each character in teeth[person][row][position]


2. Process menu choices
    2.1 Repeat until the choice is X
        2.1.1 Get menu choice
              Print the menu, read a letter, convert to upper case
              While the letter is not P, E, R or X
                  Print "Invalid menu option, try again" and read again
        2.1.2 Depending on the choice
              P: print teeth records (2.2)
              E: extract a tooth (2.3)
              R: report root canals (2.4)
    2.2 Print teeth records
        For each person
            Print the name
            For each row (Uppers, Lowers)
                Print the row label
                For each tooth position that holds a tooth
                    Print the tooth number and its letter, e.g. "1:B"
    2.3 Extract a tooth
        2.3.1 Get member: read a name, re-ask until it matches a family
              member (ignoring case)
        2.3.2 Get layer: read U or L (either case), re-ask if invalid,
              convert to row 0 or 1
        2.3.3 Get tooth number: read a number
              If it is outside 1 to the number of teeth in that row
                  Print "Invalid tooth number, try again" and read again
              Else if that tooth is already M
                  Print "Missing tooth, try again" and read again
        2.3.4 Set that tooth to M
    2.4 Report root canals
        2.4.1 Count the I, B and M teeth for the whole family
        2.4.2 Solve I*x^2 + B*x - M = 0 with the quadratic formula
              (a = I, b = B, c = -M)
        2.4.3 Display both roots to 2 decimal places


3. Print "Exiting the Floridian Tooth Records "
